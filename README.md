# Agent Academy

A practical series for noncoding professionals and business owners who want to delegate useful work to AI agents, set boundaries, and verify results.

**No coding setup is required.** You can work through the exercises in an AI workspace that has the public search and page-reading tools you choose to use. Tool availability and permissions vary; follow your workspace's actual controls.

## Start here

1. Read [Episode 1: What Is an Agent?](episodes/01-what-is-an-agent.md) and try its briefing exercise.
2. Keep the task small, use public information, and stop at a draft for your review.
3. Open at least one cited source yourself. Compare the actual wording before and after your feedback.
4. Use the [author review guide](author/episode-01-review.md) for production notes. The canonical script is a separate Google Doc and may not be accessible to learners.

An agent is a system that can work toward a goal by choosing steps, using available tools, and adjusting what it does based on results. A chat interface alone does not prove or disprove that behavior. A long prompt or a displayed plan does not prove the actions occurred. Humans still define the job, access, approval requirements, and checks. A useful working pattern is:

**Goal → Choose a step → Use a tool → Inspect the result → Continue or stop**

## How to use this workbook

Copy a prompt into a tool-enabled workspace only after checking what it can access and do. Do not include confidential or client information. A prompt cannot enforce security by itself; the tool's actual permissions and your review are what matter. Stop before sending, publishing, purchasing, signing up, contacting someone, or connecting business data.

Scripts stay in their canonical Google Docs. The author guide links Episode 1's script for production/review and is not a learner-facing script download.
