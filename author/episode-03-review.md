## 12-minute recording pass

| Time | On screen | Talking point |
| --- | --- | --- |
| 00:00–00:45 | Two conflicting fictional policies, then title | “I can give AI a perfectly clear job and it still can't know which policy we use.” |
| 00:45–02:00 | The four FAQ questions and fixed prompt | Episode 2 gave it a job. Today the job stays fixed while we change its evidence. |
| 02:00–03:30 | Run A, no sources | If it asks for the rules or marks gaps, give it credit. That is a useful stop. |
| 03:30–06:30 | Run B, S1/S2 and answers | Point at the old 48-hour hold, then the superseding current rule. Don't let confidence substitute for version status. |
| 06:30–09:30 | Run C, one note | Read just the one source needed. Check the file event if shown; otherwise distinguish an attachment from a manual paste. Trace one answer to the exact line. |
| 09:30–11:00 | A/B/C comparison | Same job, different evidence. Tool access didn't make the first two answers any more true; the correct source did. |
| 11:00–12:00 | Closing assignment | Pick one small draft, name the current source and one missing fact, choose the smallest way to get it. Next: boundaries. |

## Rehearsal checks

1. Open the job prompt, packet, and operations note before recording. Start clean chats on the same model where practical. Keep the channel tools read-only or disconnected and never connect a real workspace just for footage.
2. Check the output for the four decisive distinctions: interest is not reservation; no payments through the form is not a free workshop; a waitlist is opt-in and not a guarantee; use the stated accessibility channel without fabricating a URL.
3. If A already does the right thing, don't manufacture a bad answer. If B answers an unsupported question, call out the gap. If C won't read the file, use the manual fallback and be explicit that you did the lookup.
4. If the live model is slow, use the workbook's illustrative comparison as a cutaway. Label it “Illustrative, not a live result.” No claim that a tool event ran if the interface does not show one.
